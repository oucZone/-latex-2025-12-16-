## 说明
本项目来源于https://github.com/oucailab/OUC-LaTex-master
，并在此基础上，严格按照中国海洋大学提供的Word版学位论文格式要求和外观重新进行了优化修改

## 主要改动如下：

1.新增**四级标题格式：\subsubsection{}**

2.新增**英文目录中摘要项：**

             Abstract (In Chinese)
             Abstract (In English)
             
3.新增**注释表**
             注释表
             Abbreviation
             
4.优化了**首页（cover.tex）的整齐度**

5.优化了**一级标题和页眉的距离**

6.优化了**页边距及页眉、页脚的位置**

7.优化了**各级标题的数字字体，改为了Times New Roman**

8.优化了**一级标题的字体间距**

9.加粗了**ABSTRACT和Contents标题**

10.修复**图表标题中引用参考文献会导致参考文献乱序的问题**

11.修复**长英文导致不分行，超出页面的问题**，使用\seqsplit{}将长英文包括进去即可。

12.修复**英文目录和插图清单中间，可能会出现空白页的问题**，详情见main.tex文件里面关于图表清单、插图清单的代码注释。

13.修复**图标题中引用的参考文献在插图清单中显示的问题**，详情见正文中关于图例的使用说明。

14.修复**latex默认页面底部对齐，导致拉伸出现段间距过大的问题**，在\begin{document}前面加入\raggedbottom。

15.修复**参考文献title会自动变成句子首字母大写的问题**，在oucauthoryear.bst中禁用自动大小写转换，题目会保持BibTeX数据库中原始大小写格式。

16.修复**参考文献引用格式中URL优先：如果URL和DOI同时存在且DOI在URL字段内，则不显示DOI，只显示URL的问题**，改为**DOI优先，如果URL和DOI同时存在，只显示DOI，如果只有URL就显示URL**。

17.修复**中英文目录里面，发表的学术成果这个地方的页码不一致问题**，在main.tex文件中相关位置，插入\clearpage。
...

## 如何使用
推荐使用 **Overleaf** 使用本模板，具体方法如下：

1. 下载项目，形成.zip 文件
2. 在 Overleaf 中上传该 .zip 文件以创建一个新 Overleaf 项目
3. 在 Overleaf 界面选择 "setting"
   - 选择 "Compiler" 为 "XeLaTeX"
   - 选择 "TeX Live version" 为 "2019" 或者更新的版本
5. 随后，可以正常编译成pdf
